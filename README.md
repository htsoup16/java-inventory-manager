# Enterprise Device Management & Checkout System (DMCS)

A modular, Object-Oriented Java console application designed for asset management and loan processing within a public infrastructure environment (e.g., municipal libraries, corporate inventory). 

## 🚀 Key Features
* **Inventory Control & Maintenance:** Complete CRUD-adjacent capability to programmatically list, add, search, and edit active electronic devices.
* **State-Driven Loan Architecture:** Tracks device availability dynamically using real-time asset flags to process checkouts and mitigate allocation conflicts.
* **Preloaded Bootstrapping:** Boots with a persistent memory layer pre-populated with default hardware records for demonstration stability.
* **Fault-Tolerant Loop UX:** Implements do-while selection logic alongside manual exception blocks to guarantee zero-crash execution.

## 🛠️ Technical Concepts Demonstrated
* **Object-Oriented Design (OOD):** Built using strong instantiation patterns, minimizing static dependencies to enforce encapsulation and domain modeling.
* **Dynamic Collections Framework:** Leverages `ArrayList` objects to handle variable data scales, ensuring runtime memory allocation remains reusable and extensible.
* **Algorithmic String Matching:** Features custom target search fields to parse array indexes and output localized matches.
* **Single Responsibility Principle (SRP):** Segregated utility operations, execution loops, and foundational item blueprints into highly decoupled classes.

## 📦 Requirements & Environment
* **Language:** Java (JDK 8 or higher)
* **IDE Used:** Eclipse IDE
